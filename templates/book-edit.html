iWhat happens to replaced files and readers' data
{{ if .Incoming }}

A book has one file per format. A file of the book's that a new one replaces goes to the Recycling Bin, where it can be restored from. Readers keep their places in it, but their bookmarks and highlights in it go to the bin with it: they'd land in the wrong places in a different file.

{{ else }}

The other books go to the Recycling Bin, whole, so each can be restored as it was. A file of the kept book's that another replaces is kept in the bin too. Readers' favorites, shelves and places from every book are copied to the kept book. Bookmarks and highlights are tied to the file they were made in: they follow only where a book's file in that format is byte for byte the one kept.

{{ end }}
