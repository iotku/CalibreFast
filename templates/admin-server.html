Notices to everyone

A banner at the top of every page for everyone using the server, such as expected downtime or a new address. Each person can dismiss it on their device; it's pinned in their notifications menu until it ends, and goes for everyone when it ends.

    None in force.

    Backups

    {{ if .Backups.On }}

    The app's data (accounts, reading, highlights, shelves) is backed up daily, and Calibre's metadata.db weekly when it changed, into {{ .Backups.Dir }}. The newest {{ .Backups.Keep }} of each are kept. Backups hold everyone's accounts and reading: keep them as safe as the server's data folder. The key for users' Hardcover sign-ins (secrets.key) is never in a backup or a download; copies stay in the data folder.
