Filter tips

Each column's box filters that column; every box must match.

  • word contains the text (any case or accent); in Tags, Languages and Formats, any one of them does
  • =Fiction is exactly that; a lone = is empty (no tags, no publisher…)
  • !word doesn't contain it; != isn't empty
  • sci|fant either of them
  • <2000, >=2010-06 compare dates
  • a dashed format is a file in the book's folder that metadata.db doesn't list (Calibre won't show it); folder in Formats finds them
  • the tick box beside a column's name: only books with nothing there, or the default a book gets when nothing was known (author or title Unknown, language und)

Click a tag, language or format in a row to filter by it; +N shows the ones that don't fit. Double-click a title, author, publisher, date, tags or languages to edit it there (tags and languages also have a ✎ button before them) (Enter saves, Esc cancels). Shift-click ticks a range.
