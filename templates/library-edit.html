Each column's box filters that column; every box must match.

  • word contains the text (any case or accent); in Tags, Languages and Formats, any one of them does
  • =Fiction is exactly that; a lone = is empty (no tags, no publisher…)
  • !word doesn't contain it; != isn't empty
  • sci|fant either of them
  • <2000, >=2010-06 compare dates
  • a dashed format is a file in the book's folder that metadata.db doesn't list (Calibre won't show it); folder in Formats finds them
  • the tick box beside a column's name: only books with nothing there, or the default a book gets when nothing was known (author or title Unknown, language und)

Click a title, author, series, publisher, date, tags or languages to edit it there; click a tag or language to edit just that one (empty removes it). Enter saves, Esc cancels; a series' number goes in brackets: Dune [2]. Right-click a cell, tag, language or format for its options (on a touch screen, long-press it): show only books with that, hide them, edit, copy, split a tag; for authors written “Last, First” or “A; B”, put the first name first or split them (as the metadata editor's Split does), for that book or every selected one. +N shows the ones that don't fit. Ctrl-click (⌘-click on a Mac) ticks a row, Shift-click a range; on a touch screen a tap ticks the row. A tag's ✕ removes it from that book at once; Undo brings it back.

Drag the edge of a column's name to resize it; double-click the edge for its usual width.
