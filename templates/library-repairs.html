Library repairs

These shouldn't be necessary. They fix metadata.db for books added by older versions of CalibreFast, or changed outside Calibre, so that Calibre finds their files. Only the database is modified: no file is renamed, moved or removed.

Checking looks at every book's files, which can take a while on a big library. Nothing changes until you press a Repair button.

File names Calibre can't find

Calibre finds a format's file by the name metadata.db gives it. These files are under another name; the repair points each at the one file in its book's folder with that format's extension.

    These books list no formats, so Calibre shows none, though their folders hold book files (CalibreFast opens them anyway). The repair adds a row for each format with exactly one file; a format with several is left for you to sort out. The bulk editor shows these books too.
